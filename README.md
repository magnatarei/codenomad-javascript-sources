# 50 sources de JavaScript da CodeNomad Academy

Este repositório reúne 50 programas completos em JavaScript para Node.js, cada um num único arquivo, prontos para rodar e explicados onde importa. Ele serve para quem está aprendendo JavaScript e quer ler código de verdade, e para quem já programa e quer uma calculadora, um validador, um organizador de pastas, um servidor HTTP ou um jogo de terminal sem instalar nada. Cada source faz uma coisa bem definida, valida a entrada, dá mensagens de erro claras e termina com três exercícios para você continuar. É um projeto da [CodeNomad Academy](https://codenomad.org), plataforma de autoestudo em desenvolvimento de software.

## Como rodar

Requisito: Node.js 18 ou mais novo. Nada além dos módulos nativos (`fs`, `path`, `readline`, `http`, `https`, `crypto`, `os`). Não há `npm install`, não há `package.json`, não há `node_modules`.

Rodar uma source com argumentos reais:

```bash
node sources/01_calculadora_juros_compostos.js 1000 0.8 24 200
```

Rodar a demonstração de qualquer source:

```bash
node sources/01_calculadora_juros_compostos.js --demo
```

A flag `--demo` executa uma demonstração completa com dados de exemplo, sem pedir nada no teclado e sem acessar a internet. Ela termina sozinha em poucos segundos e é o jeito mais rápido de ver o que o programa faz antes de ler o código.

Sem argumento nenhum, o programa mostra o uso. Os jogos (46 a 50), sem argumentos, entram no modo interativo. Os caminhos nos exemplos abaixo partem da raiz do repositório; se você entrar na pasta `sources/`, basta tirar o `sources/` do comando.

## Como este material é organizado

Um arquivo por programa. Cada source vive em `sources/NN_nome.js`, em que `NN` é o número de 01 a 50. Não há módulos compartilhados: você copia um arquivo e ele funciona sozinho.

Cabeçalho padrão. Todo arquivo começa com o mesmo bloco de comentário `/** ... */`, com cinco campos: "O que faz", "Como usar" (o comando real e o comando com `--demo`), "O que você aprende", "Requisitos" e a licença. Dá para saber se a source serve antes de rolar a tela.

Comentários onde importa. Os comentários estão nos pontos em que um aluno costuma tropeçar: por que dinheiro se calcula em centavos inteiros, por que `Math.random` não serve para senhas, por que `shift()` é caro numa fila, por que o objeto `Date` engana com fuso horário. O resto do código fala por si.

Bloco "Para ir além". Cada arquivo termina com três exercícios sugeridos para você estender o programa com o que acabou de ler.

Só biblioteca padrão. Os 50 arquivos usam apenas o que vem com o Node.js: `fs`, `path`, `os`, `crypto`, `http`, `https`, `readline` e os objetos da própria linguagem (`Map`, `Set`, `BigInt`, `Intl`, `JSON`, `Promise`). Isso é de propósito: você aprende a linguagem, não um framework.

CommonJS puro. Cada arquivo começa com `'use strict'` e usa `require()`. Assim `node arquivo.js` funciona em qualquer pasta, sem `package.json` e sem configurar `"type": "module"`.

Dois modos em toda source. Com argumentos, o programa faz o trabalho de verdade. Com `--demo`, ele mostra tudo o que sabe fazer sem depender de você.
